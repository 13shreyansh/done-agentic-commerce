Buying everyday products still makes people search, compare, approve payments, and trust black-box agents. DONE changes that.

DONE filters hard constraints, ranks eligible products with a public policy, and asks once for a single-use spending mandate. After approval, it completes the workflow and returns a receipt with inspectable proof.

AWS Lambda validates the execution evidence. DynamoDB prevents duplicate orders. CloudWatch provides traceability.

The merchant checkout and iMessage interface are clearly labelled sandboxes, while the payment and AWS proofs are live.
